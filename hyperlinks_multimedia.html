Hyperlinks, Images & Multimedia

Learn to connect webpages, display images, and add sound and video. Then combine these skills to build a mini learning webpage.

Suggested time: 60–90 minutes · Level: Beginner

GoalsHyperlinksImages MultimediaBuild a pageQuiz

Learning goals

By the end of this lesson, you should be able to:

  • Create links to other websites, other HTML files, and sections on the same page.
  • Insert images using <img>, src, and meaningful alt text.
  • Add audio and video players with controls.
  • Use correct file paths and test whether media loads.
  • Use media responsibly by checking permission, licence, and accessibility needs.

1. Hyperlinks: connect the web

A hyperlink is a clickable link that takes a visitor to another page, website, file, or section. The HTML <a> element is called an anchor.

<a href="https://www.gov.za/">
  Visit the South African government website
</a>
  • <a> starts the link.
  • href gives the destination address.
  • The words between the tags become the clickable text.
  • </a> ends the link.
Try this link:

Visit the South African government website

Common hyperlink types

External link
<a href="https://example.com/">
  Visit Example
</a>

Opens another website.

Another page in your site
<a href="about.html">
  About us
</a>

Works when about.html exists at that path.

Section on this page
<a href="#wildlife">
  Jump to wildlife
</a>

<h2 id="wildlife">Wildlife</h2>

The fragment matches an element's id.

Email link
<a href="mailto:teacher@example.com">
  Email the teacher
</a>

Replace the example address with an authorised address.

Remember: use clear link text such as “Read the lesson” instead of “click here” when possible. If using target="_blank", include rel="noopener".

Quick check

In <a href="about.html">About</a>, which part tells the browser where to go?

Show answer

The href attribute. Its value, about.html, is the destination.

2. Images: make a webpage visual

The <img> element displays an image. It is a void element, which means it does not need a closing tag.

<img src="images/lion.jpg"
     alt="A lion resting in the grass"
     width="400"
     height="267">
  • src means source: the path or URL to the image.
  • alt gives a text alternative describing the image's purpose or content.
  • width and height describe the intended display dimensions.

Live image example

Local images and file paths

A project may be arranged like this:

my-website/
├── index.html
└── images/
    ├── lion.jpg
    └── mountain.jpg

From index.html, the path to the lion is images/lion.jpg. The folder name, spelling, and file extension must match.

Add a caption

<figure>
  <img src="images/mountain.jpg"
       alt="Table Mountain above Cape Town"
       width="600" height="400">
  <figcaption>
    Table Mountain is a famous landmark.
  </figcaption>
</figure>

<figure> groups the image and its related content. <figcaption> adds a visible caption. Captions and alternative text have different jobs.

Keep images responsive

img {
  max-width: 100%;
  height: auto;
}

This CSS helps an image fit its container without stretching its proportions.

Accessibility tip: write useful alt text for meaningful images. For purely decorative images, use alt="" so assistive technology can skip them.

3. Multimedia: audio and video

Multimedia combines media types such as text, images, sound, and video to communicate information.

Adding audio

<audio controls>
  <source src="audio/nature.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

The controls attribute displays playback controls. The <source> element specifies the media file and its format.

Audio player example

This sample uses a public demonstration file and requires an internet connection. If the host changes, use your own permitted audio file.

Adding video

<video controls width="640" height="360">
  <source src="videos/wildlife.mp4" type="video/mp4">
  Your browser does not support video.
</video>

Useful attributes include controls, width, height, poster (a preview image), muted, and loop.

Video player example

This public sample demonstrates a video player. Replace it with a video you have permission to use.

Captions make videos more accessible

<video controls>
  <source src="videos/wildlife.mp4" type="video/mp4">
  <track src="captions/wildlife-en.vtt"
         kind="captions"
         srclang="en"
         label="English">
</video>

The WebVTT caption file must exist and contain correctly formatted timestamps and caption text. Provide captions or transcripts where appropriate, and avoid unexpected autoplay.

Embedding an online video

Some video services allow embedding with an <iframe>. Use the embed URL provided by the service, set a descriptive title, and check that the video owner permits embedding.

Be responsible: use media you created or are licensed to use. Check copyright, permission, and attribution requirements before publishing.

4. Practical project: South Africa — A Land of Wonders

Combine hyperlinks, images, audio, and video to create a small learning page. Save this as index.html. Add your own media files in the folders shown below to make the local audio and video work.

south-africa/
├── index.html
├── images/
│   └── table-mountain.jpg
├── audio/
│   └── nature.mp3
└── videos/
    └── wildlife.mp4
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>South Africa: A Land of Wonders</title>
  <style>
    body { font-family: Arial, sans-serif; line-height: 1.6;
           max-width: 850px; margin: auto; padding: 1rem; }
    header, footer { background: #145c42; color: white;
                     padding: 1rem; text-align: center; }
    nav { display: flex; flex-wrap: wrap; gap: 1rem; padding: 1rem 0; }
    img, video { max-width: 100%; height: auto; }
    section { padding: 1rem 0; }
  </style>
</head>
<body>
  <header id="home">
    <h1>South Africa: A Land of Wonders</h1>
    <p>Discover our country through the web.</p>
  </header>

  <nav aria-label="Main navigation">
    <a href="#home">Home</a>
    <a href="#wildlife">Wildlife</a>
    <a href="#sounds">Sounds</a>
    <a href="#video">Video</a>
  </nav>

  <main>
    <section id="wildlife">
      <h2>Explore our country</h2>
      <figure>
        <img src="images/table-mountain.jpg"
             alt="Table Mountain overlooking Cape Town"
             width="800" height="533">
        <figcaption>Table Mountain is a famous landmark.</figcaption>
      </figure>
      <p>Explore <a href="https://www.sanparks.org/">
        South African National Parks</a>.</p>
    </section>

    <section id="sounds">
      <h2>Listen to nature</h2>
      <audio controls preload="metadata">
        <source src="audio/nature.mp3" type="audio/mpeg">
        Your browser does not support audio.
      </audio>
    </section>

    <section id="video">
      <h2>Watch and learn</h2>
      <video controls width="640" height="360">
        <source src="videos/wildlife.mp4" type="video/mp4">
        Your browser does not support video.
      </video>
    </section>
  </main>

  <footer>
    <p>Created by a young web developer!</p>
    <a href="#home" style="color:white">Back to top</a>
  </footer>
</body>
</html>

Project checklist

  • Does each navigation link jump to the correct section?
  • Does the image load and have meaningful alternative text?
  • Do the audio and video players display controls?
  • Have you tested the page at a narrow screen width?
  • Have you checked that you have permission to use each media file?
