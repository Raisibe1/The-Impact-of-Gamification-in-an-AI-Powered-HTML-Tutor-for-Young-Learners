1️⃣ Step 1: Ordered Lists (<ol>)

An ordered list is used when the order matters. Think of a recipe, a set of steps, or a top-10 ranking. Browsers number the items automatically. 

<ol>
  <li>Boil the water</li>
  <li>Add the pasta</li>
  <li>Cook for 8 minutes</li>
</ol>
TagWhat it does
<ol>Opens the ordered list container.
<li>Wraps a single list item.
</ol>Closes the list.

🎨 Useful attributes

AttributeExampleResult
typetype="A"A, B, C…
typetype="i"i, ii, iii…
startstart="5"Begins counting at 5
reversedreversedCounts backwards

🔘 Step 2: Unordered Lists (<ul>)

An unordered list is used when the order does not matter. Browsers show each item with a bullet point. 

<ul>
  <li>Springbok</li>
  <li>Elephant</li>
  <li>Lion</li>
</ul>

💡 Rule of thumb: if you could shuffle the items and nothing breaks, use <ul>. If the sequence matters, use <ol>.

Use <ol> when…Use <ul> when…
Instructions or recipesShopping list
Top 10 rankingFeatures of a product
Steps in a processNavigation menu
Legal clausesHobbies or interests

🪆 Step 3: Nested Lists

A nested list is a list inside a list item. It is perfect for organising information into categories and sub-categories. 

<ul>
  <li>Mammals
    <ul>
      <li>Elephant</li>
      <li>Lion</li>
    </ul>
  </li>
  <li>Birds
    <ul>
      <li>Eagle</li>
      <li>Penguin</li>
    </ul>
  </li>
</ul>

🚨 Golden rule of nesting

The inner list must sit inside an <li>, right before that item's closing tag. If you put it anywhere else, the browser will "fix" your code in ways you didn't expect.

✅ Correct vs ❌ Incorrect

✅ Correct

<ul>
  <li>Fruit
    <ul>
      <li>Apple</li>
    </ul>
  </li>
</ul>

❌ Incorrect

<ul>
  <li>Fruit</li>
  <ul>
    <li>Apple</li>
  </ul>
</ul>

📊 Step 4: Tables (<table>)

A table organises information into rows and columns. Use tables for data (timetables, prices, results) — never for page layout.

🏗️ The four core tags

TagMeaning
<table>Wraps the entire table.
<tr>Table Row — one row of cells.
<th>Table Header — a bold heading cell.
<td>Table Data — a normal cell.

📅 Example: A school timetable

<table>
  <tr>
    <th>Time</th>
    <th>Monday</th>
    <th>Tuesday</th>
  </tr>
  <tr>
    <td>08:00</td>
    <td>Maths</td>
    <td>English</td>
  </tr>
</table>

♿ Step 5: Captions & Accessible Tables

A table without a title is like a chapter without a heading. Adding a <caption> and using scope on your header cells makes tables usable for everyone — including people who use screen readers.

🏷️ Adding a caption

<table>
  <caption>Grade 7 Timetable — Term 1</caption>
  <tr>
    <th scope="col">Time</th>
    <th scope="col">Monday</th>
  </tr>
  <tr>
    <th scope="row">08:00</th>
    <td>Maths</td>
  </tr>
</table>
AttributeMeaning
scope="col"This header describes a column.
scope="row"This header describes a row.

🔊 Screen readers announce cells like this: "Monday, 08:00, Maths." Without scope the reader can only guess which header belongs where.
