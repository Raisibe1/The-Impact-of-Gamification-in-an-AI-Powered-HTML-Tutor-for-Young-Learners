\## Folder Purpose



| Folder | Purpose | Owner |

| :--- | :--- | :--- |

| `data/raw/` | Original downloaded datasets | Data Engineer |

| `data/processed/` | Cleaned data (regenerated by script) | Data Engineer |

| `data/reference/` | Small reference files (syllabus, QA pairs) | Data Engineer |

| `docs/` | Documentation for all deliverables | Everyone |

| `notebooks/` | Jupyter notebooks for EDA and analysis | Data Engineer / ML |

| `scripts/` | Python scripts for automation | Data Engineer |

| `outputs/figures/` | Visualizations and screenshots | Everyone |

| `outputs/models/` | Trained ML models | ML Engineer |

| `backend/` | FastAPI application | Backend Developer |



\---



\## Why This Structure?



| Principle | Explanation |

| :--- | :--- |

| \*\*Separation of concerns\*\* | Data, code, docs, and outputs are separate |

| \*\*Reproducibility\*\* | Anyone knows where each component belongs |

| \*\*Git-friendly\*\* | Large files are gitignored, code is tracked |

| \*\*Team collaboration\*\* | Each team member has a clear workspace |

| \*\*Scalability\*\* | New files go into the right folder |
