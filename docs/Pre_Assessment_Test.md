\### Part 2: Basic Knowledge



\*\*2. What does HTML stand for?\*\*

A) HighText Markdown Language

B) HyperText Markup Language

C) Hyperlink and Text Markup Language



\*\*3. What is the main purpose of HTML?\*\*

A) To make web pages look pretty with colours

B) To define the structure and content of a webpage

C) To make the internet run faster



\*\*4. Which tag is used to create a normal paragraph of text?\*\*

A) `<p>`

B) `<h1>`

C) `<br>`



\*\*5. Which heading tag makes the biggest text on the page?\*\*

A) `<h6>`

B) `<h3>`

C) `<h1>`



\*\*6. Which tag is used to add an image to a webpage?\*\*

A) `<image>`

B) `<img>`

C) `<picture>`



\*\*7. How do you create a clickable link to another website?\*\*

A) Using the `<a>` tag and the `href` attribute

B) Using the `<link>` tag and the `src` attribute

C) Using the `<p>` tag and the `url` attribute



\*\*8. Which tag creates a bulleted (unordered) list?\*\*

A) `<ol>`

B) `<li>`

C) `<ul>`



\*\*9. What is a "web browser"?\*\* 

\*(Example: Google Chrome, Firefox, Safari)\*

A) A program that helps you write HTML code

B) A program that reads HTML code and displays it as a webpage

C) A program that stores all the images on the internet



\*\*10. Which tag do you use to start a completely new line without making a new paragraph?\*\*

A) `<br>`

B) `<p>`

C) `<hr>`



\*\*11. If you want to make a word \*\*bold\*\*, which tag do you use?\*\*

A) `<strong>` or `<b>`

B) `<bold>`

C) `<big>`
