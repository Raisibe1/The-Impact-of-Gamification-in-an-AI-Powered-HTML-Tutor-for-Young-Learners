\# Mozilla Web Literacy - Building Strand Competencies



\## Source

\- Framework: Mozilla Web Literacy Map

\- URL: https://foundation.mozilla.org/en/initiatives/web-literacy/

\- Accessed: 29/07/2026



\## Overview

The Web Literacy Map is organized into three strands:

\- \*\*Exploring\*\* - reading the web

\- \*\*Building\*\* - writing the web (our focus)

\- \*\*Connecting\*\* - participating on the web



\## Building Strand Competencies (Corrected)



| Competency | Description |

| :--- | :--- |

| \*\*Composing for the Web\*\* | Creating and curating content for the web |

| \*\*Remixing\*\* | Modifying existing web resources to create something new |

| \*\*Designing for the Web\*\* | Enhancing visual aesthetics and user experiences |

| \*\*Coding/Scripting\*\* | Creating interactive experiences on the web |

| \*\*Accessibility\*\* | Communicating in a universally-recognisable way |
